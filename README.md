# 🪙 GoldRateBD Widget Demo

বাংলাদেশের **লাইভ সোনা ও রুপার দাম** এবং **ইন্টার‌্যাক্টিভ মূল্য ইতিহাস চার্ট** দেখানোর জন্য [GoldRateBD.com](https://goldratebd.com) এর অফিসিয়াল উইজেট ব্যবহার করে তৈরি একটি সহজ ওয়েব পেজ।

## 📁 ফাইল স্ট্রাকচার

```
goldratebd-widget/
├── index.html    # মূল পেজ — দুটি উইজেট এমবেড করা আছে
├── style.css     # ডার্ক থিমের সুন্দর, রেসপন্সিভ স্টাইল
└── README.md     # এই ফাইল
```

## ✨ ফিচার

- 📊 **লাইভ প্রাইস টেবিল** — সোনা ও রুপার বর্তমান বাজারদর স্বয়ংক্রিয়ভাবে আপডেট হয়
- 📈 **ইন্টার‌্যাক্টিভ চার্ট** — বিগত দিনের দামের ইতিহাস গ্রাফ আকারে
- 📱 সম্পূর্ণ রেসপন্সিভ ডিজাইন (মোবাইল ও ডেস্কটপ)
- 🎨 আধুনিক ডার্ক গ্লাস ইফেক্ট থিম

## 🚀 কীভাবে ব্যবহার করবেন

### লোকালি চালানো
`index.html` ফাইলটি যেকোনো ব্রাউজারে খুলুন — কোনো সার্ভার বা বিল্ড স্টেপের প্রয়োজন নেই।

### GitHub Pages-এ হোস্ট করতে
1. এই রিপোজিটরি GitHub-এ পুশ করুন
2. **Settings → Pages** এ যান
3. Source হিসেবে `main` ব্রাঞ্চের `/ (root)` নির্বাচন করুন
4. কয়েক মিনিট পর সাইটটি লাইভ হবে: `https://<আপনার-ইউজারনেম>.github.io/<রিপো-নাম>/`

### অন্য ওয়েবসাইটে উইজেট যোগ করতে
নিচের কোড কপি করে আপনার পেজের `<body>` তে বসান:

```html
<!-- Live Gold & Silver Price Widget -->
<div id="priceTable"></div>
<script src="https://goldratebd.com/price.js"></script>

<!-- Interactive History Chart Widget -->
<div id="goldChartWidget"></div>
<script src="https://goldratebd.com/chart.js"></script>
```
